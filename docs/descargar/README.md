# descargar/

- `Checa.apk`: lo sube automáticamente el workflow `herramientas/publicar-apk.yml` (instalado en el repo de la app) al publicar un Release.
- `version.json`: versión, fecha (AAAA-MM-DD) y tamaño (texto libre, p. ej. "18 MB") que muestra el botón de descarga. Actualízalo junto con el APK.
