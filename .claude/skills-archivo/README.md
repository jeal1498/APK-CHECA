# Skills archivadas

Skills de marketing que Checa no usa hoy. Están aquí para que **no se carguen** en cada conversación (ahorra contexto).
Para volver a usar una: `git mv .claude/skills-archivo/<nombre> .claude/skills/<nombre>` y pasar su entrada de
`skills-archivo/skills-lock.json` al `skills-lock.json` de la raíz.
