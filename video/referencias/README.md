Videos de otros creadores que Eduardo elige como **referencia de diseño** para los siguientes videos de Checa. Solo se usan para tomar ideas (estructura, ritmo, look); no se republican ni se copian sus marcas, logos o textos.

|---|---|---|---|
| `sistema-ia-equipo-marketing.mp4` | TikTok de un «sistema de IA que reemplaza un equipo de marketing» (10 nov 2026, 1:40, 576×1024) | Fondo claro; mapa grande de módulos que se acerca; cadena de nodos arriba con el módulo activo; tarjeta blanca con el contenido; subtítulos blancos con contorno negro; «Módulo uno, dos, tres» | CHECA 34 «Sistema que decide por ti» (estilo `claro`, `_base/claro/`) |

## Cómo agregar una referencia nueva
1. Copia el mp4 aquí con un nombre corto (`tema-autor.mp4`).
2. Agrega su fila a la tabla (qué es, qué tomamos).
3. Descríbela en `.claude/skills/video-checa/references/narrador.md` si define un estilo nuevo.
4. El mp4 se commitea una sola vez.
