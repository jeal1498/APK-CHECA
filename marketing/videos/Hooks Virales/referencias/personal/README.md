# Referencias · 000 Personal

Videos (mp4) y capturas de otros creadores que Eduardo elige como **referencia visual** para los Hooks Virales de `000 Personal`. Solo se toman ideas (estructura, ritmo, look); no se republican ni se copian marcas, logos o textos.

- `videos/`: mp4 (nombre corto: `tema-autor.mp4`).
- `capturas/`: imágenes (`tema-autor.png`).

| Archivo | Qué es | Qué tomamos | Hooks hechos con él |
|---|---|---|---|
| _(vacío: se agrega una fila por referencia)_ | | | |

## Al agregar una referencia nueva
1. Copiar el archivo a `videos/` o `capturas/`.
2. Agregar su fila arriba.
3. Antes de hacer un hook de `000 Personal`: revisar esta carpeta y decir en una línea qué toma el video de ella.
4. El mp4 se commitea una sola vez.

Estilo base actual: PS2 Style (ver `../../estilos/README.md`).
