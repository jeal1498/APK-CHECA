# 011 — Hicimos las cuentas que casi ningún conductor hace.

**Duración estimada:** 20–35 segundos

**Versión:** Checa

### Guion
**[A cámara]** Hoy vamos a hacer las cuentas que muchos dejan para después. Tomamos una oferta y revisamos pago, kilómetros y minutos; luego añadimos combustible y desgaste. **[Mostrar Checa]** Checa ayuda a revisar las métricas; tú completas el análisis con tus gastos reales. **[Cierre]** Guarda este ejercicio para tu próxima jornada.

### Nota de producción
Usar una oferta de demostración o datos autorizados; identificar claramente los ejemplos ficticios y no prometer resultados garantizados.
