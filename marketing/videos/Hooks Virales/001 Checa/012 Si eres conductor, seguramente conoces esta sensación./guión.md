# 012 — Si eres conductor, seguramente conoces esta sensación.

**Duración estimada:** 20–35 segundos

**Versión:** Checa

### Guion
**[A cámara]** Si conduces por aplicación, conoces este momento: aparece una solicitud y tienes segundos para decidir. **[Mostrar Checa]** Tener a la vista los indicadores importantes puede ayudarte a evaluar el servicio con más contexto. **[Cierre]** ¿Qué es lo primero que miras cuando aparece una oferta?

### Nota de producción
Usar una oferta de demostración o datos autorizados; identificar claramente los ejemplos ficticios y no prometer resultados garantizados.
