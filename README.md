# Mi Ruta

App Android personal: muestra un pop-up con **$/km**, **$/hora** y semáforo (conviene / regular / no conviene) cuando llega una oferta en Uber Driver o DiDi Conductor.

- Lee la pantalla con un servicio de Accesibilidad (no envía datos a ningún lado).
- Tamaño del texto ajustable (en ajustes o con A− / A+ en el pop-up).
- Modo diagnóstico para calibrar la lectura.

Cada push a `main` compila el APK con GitHub Actions y lo publica en **Releases**.
